# Week 3 – Password Cracking

## Internship
Cybersecurity & Ethical Hacking Internship – Networkwalks

## Overview
This repository contains the practical tasks completed during Week 3 of my Cybersecurity & Ethical Hacking Internship at Networkwalks.

The week focuses on password auditing, password recovery, hash extraction, and understanding password security using different cybersecurity tools.

## Module 1: Password Cracking with John the Ripper (JTR)

### Tools Used
- Kali Linux
- John the Ripper (JTR)
- Johnny GUI
- Synaptic Package Manager

### Tasks
- Installed and verified John the Ripper.
- Explored the JTR command-line interface.
- Installed Johnny GUI using Synaptic Package Manager.
- Explored the graphical interface of Johnny.
- Learned the basic concepts of password auditing and PDF password protection.

### Learning Outcomes
- Understood the functionality of John the Ripper.
- Learned how Johnny provides a graphical interface for JTR.
- Understood the difference between CLI and GUI-based tools.
